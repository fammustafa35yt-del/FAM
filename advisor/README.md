# FX1.FAM35 — مستشار صفقات الذهب (Trade Advisor)

برنامج يدرس سوق الذهب بنفس محرك استراتيجية FX1.FAM35 ويرسل لك — على
الشاشة أو على **تيليغرام** — خطة الصفقة كاملة:

- ✅ القرار: شراء / بيع / **لا صفقة** (لن يدفعك للدخول العشوائي أبداً)
- 🎯 سعر الدخول، 🛑 وقف الخسارة، 🥇 الأهداف TP1/TP2/TP3 (نظام 1:3)
- 💰 حجم اللوت المحسوب من رصيدك ونسبة مخاطرتك (يدعم حسابات **السنت**
  للأرصدة الصغيرة مثل 100$)
- 📈 حالة السوق: الاتجاه، البنية الموجية، ADX، RSI، الدعم والمقاومة

> البرنامج **لا ينفذ صفقات** — هو مستشار يرسل لك القرار وأنت تنفذ يدوياً،
> أو استخدم بوت MT5 (`FX1.FAM35.mq5`) للتنفيذ الآلي الكامل.

---

## التثبيت

```bash
pip install pandas numpy yfinance
```

## الاستخدام

```bash
# تحليل فوري ببيانات حية (فريم ساعة) لحساب 100$ بمخاطرة 2%
python3 advisor/fam35_advisor.py --equity 100 --risk 2

# فريم 15 دقيقة (سكالب) أو 4 ساعات (سوينغ)
python3 advisor/fam35_advisor.py --interval 15m --equity 100
python3 advisor/fam35_advisor.py --interval 4h --equity 100

# من ملف CSV مُصدَّر (TradingView / MT5) بدل البيانات الحية
python3 advisor/fam35_advisor.py --csv xauusd_h1.csv --equity 100
```

## ربط تيليغرام (يرسل لك القرار أينما كنت)

1. افتح [@BotFather](https://t.me/BotFather) في تيليغرام → `/newbot` →
   انسخ الـ **Token**.
2. أرسل أي رسالة لبوتك الجديد، ثم افتح في المتصفح:
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
   وخذ رقم `chat.id`.
3. شغّل:

```bash
python3 advisor/fam35_advisor.py --equity 100 --risk 2 \
    --telegram-token 123456:ABC-XYZ --chat-id 55512345
```

## وضع المراقبة المستمرة (يرسل فقط عند إشارة جديدة)

```bash
# يفحص السوق كل 15 دقيقة ويرسل تنبيهاً عند اكتمال شروط صفقة جديدة
python3 advisor/fam35_advisor.py --watch 15 --equity 100 --risk 2 \
    --telegram-token 123456:ABC-XYZ --chat-id 55512345
```

شغّله على جهازك، أو مجاناً على أي VPS صغير، أو حتى على هاتف أندرويد عبر
تطبيق **Termux** (`pkg install python` ثم نفس الأوامر).

## حاسبة الهدف (رياضيات صادقة)

```bash
python3 advisor/fam35_advisor.py --goal 10000 --days 29 --equity 100
```

تخبرك بالعائد اليومي المطلوب لهدفك وهل هو تداول أم قمار، وترسم لك
**سلّم المضاعفة** المرحلي الواقعي بدلاً منه.

## ⚠️ مهم

- الإشارة تُحسب على آخر شمعة **مغلقة** — نفّذ بسرعة أو انتظر الإشارة التالية.
- لرصيد 100$: حساب **سنت** + مخاطرة 1–2% + حد خسارة يومي 5% ثم توقف.
- لا برنامج ولا مؤشر يضمن الربح. هذه أداة قرار، والمسؤولية النهائية عليك.
