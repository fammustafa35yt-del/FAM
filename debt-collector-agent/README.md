# 🤖📞 متحدث الذكاء الاصطناعي لتحصيل الديون

برنامج متحدث ذكاء اصطناعي مستقل يتصل هاتفياً بالزبائن المتأخرين عن سداد دفعاتهم، يتحدث معهم بالعربية عن سداد الدين، يجيب على أسئلتهم، ويتفاوض على مواعيد السداد — بأدب واحترام كامل.

## كيف يعمل؟

```
make_call.py ──► Twilio (اتصال هاتفي بالزبون)
                    │
                    ▼ الزبون يرد ويتكلم
              تحويل الكلام إلى نص (Twilio Speech-to-Text عربي)
                    │
                    ▼
                app.py (خادم Flask)
                    │
                    ▼
              Claude API (توليد الرد المناسب)
                    │
                    ▼
              تحويل النص إلى كلام (Amazon Polly عربي)
                    │
                    ▼ الزبون يسمع الرد ... وتستمر المحادثة
```

- **يأخذ بيانات الزبون**: رقم الهاتف، قيمة الدين، آخر دفعة (تاريخها ومبلغها).
- **يتصل بالزبون** ويعرّف عن نفسه كمساعد آلي ويتأكد من هوية الزبون.
- **يتحدث عن سداد الدين**: يذكّر بالمبلغ، يسأل عن سبب التأخر، ويعرض حلولاً وجدولة.
- **يجيب على الأسئلة** من بيانات الزبون، ويحوّل لموظف بشري عند الحاجة.

## المتطلبات

1. **حساب Anthropic** — مفتاح API من [platform.claude.com](https://platform.claude.com)
2. **حساب Twilio** — رقم هاتف مفعّل للمكالمات الصادرة من [twilio.com](https://www.twilio.com)
3. **Python 3.10+**
4. **رابط عام للخادم** — مثلاً عبر [ngrok](https://ngrok.com) أثناء التجربة

## التشغيل

```bash
cd debt-collector-agent
pip install -r requirements.txt

# انسخ ملف الإعدادات وعبّئ بياناتك
cp .env.example .env
nano .env
```

### 1) شغّل خادم المحادثة

```bash
python app.py
```

وإن كنت تجرّب محلياً، افتح نفقاً عاماً في نافذة أخرى وضَع الرابط في `BASE_URL` داخل `.env`:

```bash
ngrok http 5000
```

### 2) اتصل بزبون

```bash
python make_call.py \
  --phone "+9665xxxxxxxx" \
  --name "أحمد محمد" \
  --debt 4500 \
  --last-payment-date 2026-05-10 \
  --last-payment-amount 500 \
  --installment 500
```

أو اتصل بمجموعة زبائن من ملف:

```bash
cp customers.example.json customers.json   # عدّل البيانات
python make_call.py --file customers.json
```

## الملفات

| الملف | الوظيفة |
|---|---|
| `make_call.py` | بدء المكالمات (زبون واحد أو قائمة) |
| `app.py` | خادم Flask يستقبل Webhooks من Twilio ويدير المحادثة |
| `agent.py` | عقل المتحدث: توليد الردود عبر Claude API وقواعد المحادثة |
| `config.py` | قراءة الإعدادات من `.env` |
| `customers.example.json` | مثال لملف بيانات الزبائن |

## قواعد المحادثة المدمجة

- يعرّف عن نفسه كمساعد **آلي** ويتأكد من هوية الزبون قبل ذكر أي معلومة مالية.
- مهذب دائماً — لا تهديد ولا ترهيب ولا ضغط.
- إذا قال الزبون إنه دفع بالفعل أو طلب موظفاً بشرياً → يسجّل طلب تحويل لموظف (يظهر في سجل الخادم).
- إذا طلب الزبون عدم الاتصال به → يؤكد ويُنهي المكالمة.
- ردود قصيرة مناسبة للقراءة الصوتية.

يمكنك تعديل شخصية المتحدث والقواعد من `SYSTEM_PROMPT` في `agent.py`.

## ⚖️ تنبيه قانوني مهم

تحصيل الديون نشاط منظّم قانونياً في معظم الدول (أوقات الاتصال المسموحة، التسجيل، الموافقات، حماية البيانات). **تأكد من التزامك بقوانين بلدك ولوائح الجهات التنظيمية قبل الاستخدام الفعلي**، ومن إبلاغ الزبائن بأن المكالمة آلية وقد تكون مسجلة إن كان ذلك مطلوباً في بلدك.

## تخصيصات ممكنة

- **صوت مختلف**: غيّر `TTS_VOICE` في `.env` (مثل `Polly.Zeina` للفصحى).
- **لهجة التعرف**: غيّر `SPEECH_LANGUAGE` (مثل `ar-AE`، `ar-EG`).
- **إشعار الفريق**: في `app.py` عند `reply.needs_human` يمكنك إضافة إرسال بريد أو رسالة Slack أو تسجيل في CRM.
