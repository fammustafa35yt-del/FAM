# 🚀 أدوات نمو قناة يوتيوب (YouTube Growth Kit)

مجموعة أدوات **شرعية 100%** لمساعدة قناتك على النمو الحقيقي — بدون أي تلاعب
بالمشاهدات. مصمّمة خصيصاً لقنوات الألعاب (Roblox) ومحتوى الـ **Shorts** مثل
قناة [**@FAM-ROBLOX35**](https://www.youtube.com/@FAM-ROBLOX35/shorts).

> ⚠️ **لماذا لا يوجد "بوت مشاهدات"؟**
> تزييف المشاهدات يخالف شروط يوتيوب وقد يؤدي إلى **حذف المشاهدات أو حظر القناة**
> وفقدان أرباح AdSense. هذه الأدوات تركّز على النمو **الحقيقي والمستدام**: ظهور
> أفضل في البحث، تفاعل أعلى، ومحتوى أقوى.

---

## ✨ الأدوات الخمس

| الأمر | الوظيفة | يحتاج مفتاح API؟ |
|---|---|---|
| `analyze` | تحليل أداء قناتك (مشاهدات، تفاعل، أفضل الفيديوهات، توصيات) | ✅ نعم |
| `seo` | توليد عناوين + وصف + كلمات مفتاحية محسّنة للبحث | ❌ لا (يعمل فوراً) |
| `competitors` | تحليل المنافسين والمواضيع الرائجة في مجالك | ✅ نعم |
| `schedule` | خطة نشر أسبوعية + أفضل أوقات النشر | ❌ لا (أو ✅ مع `--live`) |
| `ideas` | أفكار محتوى + أفكار صور مصغّرة (Thumbnails) + خطّافات | ❌ لا (يعمل فوراً) |

## 📦 التثبيت

```bash
cd youtube-growth-kit
pip install -r requirements.txt
```

يتطلب **Python 3.8+**. لا يعتمد إلا على مكتبة `requests`.

---

## 🔑 إعداد مفتاح الـ API (للأدوات التي تحتاجه)

الأمران `analyze` و `competitors` يحتاجان مفتاح **YouTube Data API v3** المجاني:

1. اذهب إلى [Google Cloud Console → Credentials](https://console.cloud.google.com/apis/credentials).
2. أنشئ مشروعاً، ثم فعّل **YouTube Data API v3**.
3. أنشئ **API Key** وانسخه.
4. انسخ ملف الإعدادات وضع مفتاحك فيه:

```bash
cp config.example.json config.json
# ثم افتح config.json وضع المفتاح
```

أو عبر متغيّر البيئة (بدون حفظ في ملف):

```bash
export YOUTUBE_API_KEY="مفتاحك_هنا"
```

> 🔒 ملف `config.json` مُستثنى في `.gitignore` — لن يُرفع مفتاحك إلى GitHub.

## 🛠️ أمثلة الاستخدام

### 1) تحليل قناتك
```bash
python -m ytkit.cli analyze
```
يعطيك: عدد المشتركين، متوسط المشاهدات، نسبة التفاعل، مقارنة Shorts مقابل
الفيديوهات العادية، أفضل 5 فيديوهات، وتوصيات تلقائية.

### 2) توليد SEO لفيديو (يعمل فوراً بلا مفتاح)
```bash
python -m ytkit.cli seo "تختيم دورز" --game doors
```
يعطيك عناوين جاهزة + وصفاً كاملاً بالهاشتاقات + قائمة كلمات مفتاحية تنسخها
مباشرةً في حقل الوسوم.

### 3) تحليل المنافسين والمواضيع الرائجة
```bash
python -m ytkit.cli competitors "roblox blox fruits" --days 30
```
يعرض أكثر الفيديوهات نجاحاً مؤخراً، الكلمات المتكرّرة في عناوينهم، والقنوات
المنافسة النشطة.

### 4) خطة النشر وأفضل الأوقات
```bash
python -m ytkit.cli schedule              # توصيات عامة
python -m ytkit.cli schedule --live       # محلّلة من أوقات فيديوهاتك الفعلية
```

### 5) أفكار محتوى وصور مصغّرة (يعمل فوراً بلا مفتاح)
```bash
python -m ytkit.cli ideas --count 12 --game "Blox Fruits"
```

## 📈 نصائح ذهبية لنمو الـ Shorts

1. **أول 3 ثوانٍ تحسم كل شيء** — ابدأ بخطّاف قوي (سؤال/صدمة/حركة).
2. **اجعل الفيديو يُعاد تلقائياً (Loop)** — النهاية تتصل بالبداية = وقت مشاهدة أعلى.
3. **الانتظام > الكمية** — جدول ثابت أهم من رشقة فيديوهات ثم انقطاع.
4. **استخدم تريند اللعبة الحالي** — انشر عن التحديثات الجديدة فور صدورها.
5. **نادِ على التفاعل** — اطلب لايك/كومنت/اشتراك بوضوح داخل الفيديو.
